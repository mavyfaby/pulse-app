# Contributing to Pulse — Bayanihan Emergency Network

*Maverick Fabroa ([@mavyfaby](https://github.com/mavyfaby))*

Thank you for your interest in contributing to Pulse. This project is built as open civic infrastructure for the Philippines, and every contribution — code, design, research, or community work — matters.

---

## Ways to contribute

**Developers**
- Backend (Rust / Tokio)
- Android mobile client (Kotlin)
- Protocol implementation and testing
- Infrastructure and deployment

**Designers**
- UX refinement and accessibility
- Visual design and iconography
- Localization and readability

**Researchers**
- Carrier behavior testing (Smart, Globe, DITO)
- Emergency response systems research
- Field testing and user interviews

**Community**
- LGU and government partnerships
- Responder network building
- Pilot coordination in your area
- Translation (Filipino, Cebuano, and other Philippine languages)

---

## Before you start

1. Read the [Research Paper](docs/RESEARCH.md) to understand the problem and approach
2. Read the relevant specification for your area:
   - [UX Specification](docs/UX-SPECIFICATION.md)
   - [Technical Specification](docs/TECHNICAL-SPECIFICATION.md)
   - [Backend Specification](docs/BACKEND-SPECIFICATION.md)
3. Check open Issues to see what's being worked on
4. Open an Issue before starting significant work — to avoid duplicating effort and to discuss the approach

---

## Development setup

*Coming in Phase 1. The codebase does not exist yet — the project is currently in research and design phase.*

Watch this repo or check Issues for updates on when development begins.

---

## Submitting changes

1. Fork the repository
2. Create a branch (`git checkout -b your-feature`)
3. Make your changes
4. Write or update tests where applicable
5. Submit a pull request with a clear description of what and why

---

## Code of conduct

Pulse is built for community safety. Contributors are expected to treat each other with respect. Harassment, discrimination, or bad-faith contributions will not be tolerated.

---

## Questions?

Open a GitHub Discussion or Issue. If you're a Philippine developer, LGU, civic tech organization, or emergency response organization interested in partnering or piloting, reach out — that conversation is especially welcome.
